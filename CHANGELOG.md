# WHALE changelog

## 1.1.0
- First public release (same code as beta 3 + the BEFORE peak safety below).

## 1.1.0 beta 3
- BEFORE at matched level: peaks held under the ceiling (no more overs into the monitors when a quiet mix is raised),
  with a slow make-up to keep the loudness matched.
- Interface, AUTO report, presets, licence messages and installer translated to English; INSTALL_EN.txt.

## 1.1.0 beta 2
- Licence: 7-day full trial, Gumroad licence key activation (online once, then offline, signed file bound to the
  computer, 5 computers per key, 30-day background re-check), 2 s of silence every 40 s after the trial.

## 1.1.0 beta 1
- AUTO: automatic low-cut, movable EQ bells (bounded least squares), comb tempo estimation, scored style detection with
  a runner-up style shown on close calls, listened passage and break warning in the report, gated loudness loop.
- New styles Afro Tech / Riddim and Afro / Dancehall; reference profiles extended.
- Presets layer on AUTO (correction + colour), 30 presets rebuilt from the reference spread; saturation and punch v2.
- Indicators measure what is heard; A/B match on loud passages; Undo AUTO; CPU -20 to -40 %.

## 1.0.0 (en cours)
- New product: WHALE Mastering (replaces FINISH's mastering; "Finish my track" and the Ableton bridge are removed).
- AUTO based on style profiles measured on real reference masters, style detection (tempo + balance), verification pass.
- 7-module chain, x4 linear-phase oversampled saturation / clipper, true-peak limiter, level-matched A/B.
- 25 factory presets, user presets, favourites.
- Animated whale scene drawn from the audio; EXPERT panel and AUTO report.
